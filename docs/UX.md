# CinemaHall для Android TV: UX и проверка результата

Цель: один APK, работа с пульта, минимум решений перед просмотром. Внешние источники каталога и раздач остаются необходимыми; собственного серверного API CinemaHall нет.

## Основные сценарии

1. **Продолжить.** Главная показывает карточки с реальным сохранённым прогрессом. Крупная кнопка возвращает к последней незавершённой серии. Завершённая серия не становится следующей по правилу «номер + 1»: следующую нужно выбирать из списка каталога.
2. **Смотреть.** Для фильма — один выбор. Для сериала без истории — сезон и серия. Качество ограничено настройкой «Авто», источники ранжируются по числу сидов. Запуск не гарантируется числом сидов: движок всё равно проверяет метаданные и конкретный файл.
3. **Выбрать вручную.** Вкладки технических профилей, внутри озвучки. HDR, Dolby Vision и разные видеокодеки сохраняются раздельно. Неизвестные признаки остаются неизвестными. Ручной выбор удерживает качество и предполагаемую озвучку при смене источника.
4. **Вернуться.** Back закрывает текущий слой. Ответы от закрытого экрана не должны открывать его заново. Плеер сохраняет прогресс и возвращает в выбор просмотра.

## Требования к лёгкости

- Не добавлять React, дублирующий каталог и отдельную базу данных.
- Подгружать раздачи при намерении смотреть. Не опрашивать весь каталог в фоне.
- Использовать штатные постеры, карточки, историю, Timeline и видеодвижок Lampa.
- Торрентный движок стартует при первой попытке просмотра. Служба сохраняет его на время жизни приложения, включая переход во внешний плеер, и останавливает при завершении основной Activity.
- Начальный кэш движка — 64 МБ. Это настройка кэша, а не обещание общего расхода RAM: WebView, видео и торрентный движок используют дополнительную память.
- Не включать перекодирование и автотрейлеры по умолчанию.
- Все изменения оформления ограничивать классом body и отключать одним переключателем.

## Проверки перед объявлением готовности

- Пульт: вход в карточку, вкладки, серии, Back и возврат фокуса.
- Раздачи: повторы по info-hash, разные magnet-параметры, отсутствующий hash, недоступный парсер.
- Серии: точное совпадение сезона и серии, пропуски номеров, спецвыпуски, sample и пакеты с несколькими сериями в одном файле.
- Плеер: сохранение позиции, переход между сериями, ошибка потока, смена источника, субтитры.
- Android: холодный старт движка, повторный старт, закрытие Activity, уход во внешний плеер, восстановление после выгрузки системой.
- Реальная приставка: 1080p AVC/AAC, HEVC, многоканальный звук и HDR проверяются отдельно. Браузерные тесты не подтверждают поддержку форматов.

## Границы версии 0.1

Распознавание озвучки сейчас выполняется по названию раздачи. Проверенных данных ffprobe, выбора конкретной MKV-дорожки по названию студии и общей базы доступных файлов пока нет. Присутствие карточки в TMDB не означает, что для неё найдена рабочая раздача. Исходники Nuvio используются как UX-ориентир; перенос его Android-движка не выполнен.
