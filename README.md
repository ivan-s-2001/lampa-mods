# CinemaHall · Lampa Mods

Лёгкая версия Lampa для Android TV: улучшенный выбор просмотра и отдельное оформление в духе Nuvio, без серверного API CinemaHall.

**Статус: 0.1 preview.** Плагины реализованы; Android-интеграция собирается отдельным workflow. Поддержка кодеков и поведение на реальной приставке ещё требуют проверки. Это не готовая копия Nuvio.

## Два плагина

- `cinemahall.js` — главная с небольшим числом рядов, продолжение просмотра, поиск через настроенные Jackett/Prowlarr, объединение по info-hash, вкладки качества и озвучек, проверка файла серии, резервные источники и меню просмотра в плеере.
- `cinemahall-look.js` — тёмная тема, крупные действия, контрастный фокус, три акцента, компактный режим и отключение анимации. Работает независимо от первого плагина.

Сборка не добавляет клиентские библиотеки. Проверки и средства сборки устанавливаются только разработчику.

## Проверка в обычной Lampa

Добавить в «Расширения → Добавить плагин»:

```
https://raw.githubusercontent.com/ivan-s-2001/lampa-mods/main/cinemahall.js
https://raw.githubusercontent.com/ivan-s-2001/lampa-mods/main/cinemahall-look.js
```

После перезапуска появятся разделы CinemaHall. Настроенные парсеры и TorrServer используются из Lampa. Обычная Lampa от установки JS-плагина не получает встроенный сервер.

Для этого режима настройка работающего источника поиска раздач всё ещё нужна. В проект не зашиты сторонние ключи и платные сервисы.

## Android TV: один APK

Workflow **Build Android TV preview** собирает приложение на базе закреплённой ревизии официальной Android-оболочки Lampa:

- веб-интерфейс и оба плагина входят в APK;
- бинарник TorrServer включён в APK и проверяется по SHA-256;
- движок запускается по запросу просмотра, доступен только на `127.0.0.1`;
- внутренний порт определяется автоматически, пользователь его не вводит;
- кэш 64 МБ задаётся с сохранением остальных настроек движка;
- приложение устанавливается отдельно от официальной Lampa (`ru.cinemahall.lampa`);
- предварительные APK собираются отдельно для `arm64-v8a` и `armeabi-v7a`, Android 8+;
- используются системный WebView и встроенный HTML5-плеер Lampa. Для форматов, которые он не поддерживает, в настройках предусмотрен системный Android-плеер.

APK находятся в Artifacts успешного запуска workflow. Это debug-сборки для тестирования; обновления между ними могут потребовать переустановки из-за смены debug-подписи. Публикация релизов и отправка в магазины не настроены.

## Разработка

Node.js 22+, Python 3. Для браузерных проверок нужен Chromium:

```sh
npm install --ignore-scripts
npx playwright install chromium
npm run check
npm test
npm run build
npm run test:browser
```

Редактировать `src/`, затем запускать `npm run build`. Сгенерированные два JS-файла хранятся в репозитории и проверяются CI.

Android workflow скачивает закреплённые upstream-исходники, применяет `android/prepare.py` и собирает `assembleLiteDebug`. Локальная подготовка использует те же версии из `android/upstream.json`.

## Ограничения

- Студия озвучки определяется по названию раздачи. Фактическую аудиодорожку выбирают в плеере; это не подтверждённый индекс MKV-дорожек.
- Автоматический повтор ограничен восемью попытками и работает в интеграции со встроенным плеером. Внешний Android-плеер управляет своими ошибками самостоятельно.
- Проигрываются только уверенно сопоставленные серии. Неоднозначные названия требуют дальнейшего улучшения парсинга.
- Каталог показывает метаданные TMDB, а не гарантированное наличие живых торрентов. Фонового массового сканирования нет.
- Полноценная интеграция ffprobe, набор русскоязычных правил на базе проверенного стороннего парсера и визуальное соответствие Nuvio ещё не завершены.

Подробные сценарии и критерии готовности: [docs/UX.md](docs/UX.md).
