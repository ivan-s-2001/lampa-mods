# CinemaHall · Lampa Mods

Лёгкая версия Lampa для Android TV: улучшенный выбор просмотра и отдельное оформление в духе Nuvio, без серверного API CinemaHall.

**Статус: 0.2 preview.** Плагины реализованы; Android-интеграция собирается отдельным workflow. Поддержка кодеков и поведение на реальной приставке ещё требуют проверки. Это не готовая копия Nuvio.

## Два плагина

- `cinemahall.js` — главная с небольшим числом рядов, продолжение просмотра, встроенные источники поиска и свои Jackett/Prowlarr, объединение по info-hash, вкладки качества и озвучек, проверка файла серии, резервные источники и меню просмотра в плеере.
- `cinemahall-look.js` — тёмная тема, крупные действия, контрастный фокус, три акцента, компактный режим и отключение анимации. Работает независимо от первого плагина.

Сборка не добавляет клиентские библиотеки. Проверки и средства сборки устанавливаются только разработчику.

## Проверка в обычной Lampa

Добавить в «Расширения → Добавить плагин»:

```
https://raw.githubusercontent.com/ivan-s-2001/lampa-mods/main/cinemahall.js
https://raw.githubusercontent.com/ivan-s-2001/lampa-mods/main/cinemahall-look.js
```

После перезапуска появятся разделы CinemaHall. Настроенные парсеры и TorrServer используются из Lampa. Обычная Lampa от установки JS-плагина не получает встроенный сервер.

Поиск включён по умолчанию: адреса публичных источников уже заданы. Свои Jackett/Prowlarr добавляются к ним из настроек Lampa. В проект не зашиты сторонние ключи и платные сервисы.

Встроены **JacRed, Knaben API v2, RuTor, Torrents.csv, APIBay, YTS и EZTV**. Последний используется для сериалов с IMDb ID; при необходимости ID запрашивается в TMDB. YTS — только фильмы. Агрегаторы возвращают результаты нескольких трекеров, а их зеркала не считаются отдельными источниками. Поиск учитывает русское и оригинальное название, год фильма и исключает известные аниме-категории.

Одновременно выполняются не более трёх запросов. Общий поиск ограничен 12 секундами, запрос — 6,5 секунды; поздние ответы не меняют экран. Повторные запросы к одному сервису разделены 2,2 секундами. Кэш в памяти: 5 минут, максимум 24 ответа по 300 записей; после ошибки источник получает паузу 60 секунд. Каждый источник отключается отдельно: «CinemaHall · просмотр». Там же есть состояние последнего поиска и очистка кэша. Настройка обычного TorrServer для отдельной Lampa остаётся необходимой.

Проверка из среды разработки: RuTor и Torrents.csv вернули результаты по открытому фильму Big Buck Bunny. Остальные публичные сервисы вернули HTTP 403 из этой сети; их доступность на приставке не подтверждена. Успешный ответ не гарантирует живых пиров. В браузере без Android-оболочки также действуют ограничения CORS сторонних сайтов. Собственный прокси для обхода CORS не используется.

## Расширения

Раздел «CinemaHall · расширения» содержит 18 позиций с установкой и отключением через штатный менеджер Lampa. При первом запуске автоматически включаются **Онлайн Мод, Цветные статусы сериалов, Платформы TMDB и Случайное из «На потом»**. Уже установленные или выключенные пользователем версии сохраняются. Эти четыре скрипта загружаются с закреплённых ревизий GitHub; для первой загрузки нужен интернет. Сам факт загрузки скрипта не подтверждает работу его онлайн-провайдеров.

В том же разделе доступны свои списки, профили, синхронизация закладок, подборки, логотипы, Torrent Styles, Jellyfin, Filmix, BwaRC, MODS’s, Showy, IPTV Skaz и два источника трейлеров. Они подключаются отдельно: некоторые требуют аккаунт, подписку, сервер или иной способ загрузки HTTP на устройстве. Их код в APK не скопирован. Отключение действующего плагина полностью применяется после перезапуска Lampa. Темы, которые заменяют наш интерфейс, и повторные менеджеры TorrServer в комплект не добавляются.

Каталог составлен по [lampaplugins/store](https://github.com/lampaplugins/store), [каталогу Lampac](https://github.com/lampac-nextgen/lampac/blob/main/Modules/LampaWeb/plugins/extensions.json) и репозиториям [levende](https://github.com/levende/lampa-plugins) / [nb557](https://github.com/nb557/plugins). Популярность определяется присутствием в этих каталогах, а не статистикой установок. GitHub-обёртки отдельных необязательных плагинов могут подгружать актуальный код с сайта автора.

## Android TV: один APK

Workflow **Build Android TV preview** собирает приложение на базе закреплённой ревизии официальной Android-оболочки Lampa:

- веб-интерфейс и оба плагина входят в APK;
- бинарник TorrServer включён в APK и проверяется по SHA-256;
- движок запускается по запросу просмотра, доступен только на `127.0.0.1`;
- внутренний порт определяется автоматически, пользователь его не вводит;
- кэш 64 МБ задаётся с сохранением остальных настроек движка;
- приложение устанавливается отдельно от официальной Lampa (`ru.cinemahall.lampa`);
- предварительные APK собираются отдельно для `arm64-v8a` и `armeabi-v7a`, Android 8+;
- используются системный WebView и встроенный HTML5-плеер Lampa. Для форматов, которые он не поддерживает, в настройках предусмотрен системный Android-плеер.

APK находятся в Artifacts успешного запуска workflow. Это debug-сборки для тестирования; обновления между ними могут потребовать переустановки из-за смены debug-подписи. Публикация релизов и отправка в магазины не настроены.

## Разработка

Node.js 22+, Python 3. Для браузерных проверок нужен Chromium:

```sh
npm install --ignore-scripts
npx playwright install chromium
npm run check
npm test
npm run build
npm run test:browser
```

Редактировать `src/`, затем запускать `npm run build`. Сгенерированные два JS-файла хранятся в репозитории и проверяются CI.

Android workflow скачивает закреплённые upstream-исходники, применяет `android/prepare.py` и собирает `assembleLiteDebug`. Локальная подготовка использует те же версии из `android/upstream.json`.

## Ограничения

- Студия озвучки определяется по названию раздачи. Фактическую аудиодорожку выбирают в плеере; это не подтверждённый индекс MKV-дорожек.
- Автоматический повтор ограничен восемью попытками и работает в интеграции со встроенным плеером. Внешний Android-плеер управляет своими ошибками самостоятельно.
- Проигрываются только уверенно сопоставленные серии. Неоднозначные названия требуют дальнейшего улучшения парсинга.
- Каталог показывает метаданные TMDB, а не гарантированное наличие живых торрентов. Фонового массового сканирования нет.
- Полноценная интеграция ffprobe, набор русскоязычных правил на базе проверенного стороннего парсера и визуальное соответствие Nuvio ещё не завершены.

Подробные сценарии и критерии готовности: [docs/UX.md](docs/UX.md).
